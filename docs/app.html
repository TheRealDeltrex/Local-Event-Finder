📍 Local Events Finder

Find things to do near you. Pick a spot, set a range, and filter by the kind of thing you're in the mood for.

⚠️ In-browser demo — limitations. The interface is fully live (location, distance, tagging, filtering), and real nearby places (museums, parks, pools…) load from OpenStreetMap. But browsers can't fetch the ticketed-event sites directly (no CORS / Cloudflare), so concerts, theatre and other scheduled events don't load here — the demo shows sample events instead. For real event listings, install the Android app or run the local Flask app (see the home page).
⏳ A search can take a minute or two — it checks several sources and OpenStreetMap.
